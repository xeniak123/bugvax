From a fix to an antibody.

Your history already holds the answers. bugvax turns each fix into a rule and keeps it only if it survives the lab.

Mine

bugvax reads your git history and picks the commits that fixed bugs. Typos, lint, formatting and dependency bumps are skipped.

Generalize

A model writes an ast-grep rule for the whole bug class, not just the line that changed, plus a template for the fix.

id: unawaited-db-commit
language: tsx
severity: error
message: "commit() is called without await"
rule:
  all:
    - kind: call_expression
    - pattern: $DB.commit($$$ARGS)
    - inside:
        kind: expression_statement
fix: await $DB.commit($$$ARGS)

Validate

The rule has to match the buggy code, stay silent on the fixed code and leave the rest of the repo alone. A second model reviews every match.

  • Matches the buggy codesrc/refunds.ts:6 before ca73865
  • Silent on the fixed codeawait db.commit(); after ca73865
  • Not too broad1 match in today's code, limit 10
  • Reviewedsrc/invoices.ts:6 confirmed as the same bug

Prove the fix

A fix template is kept only if applying it to the buggy code reproduces what the human fix did. Nothing gets fixed on a guess.

export async function voidInvoice(id: string) {
  const invoice = await db.invoices.find(id);
  invoice.status = "void";
- db.commit();
+ await db.commit();
}

template await $DB.commit($$$ARGS) reproduced ca73865

Enforce

The rules run in milliseconds in pre-commit, in CI and in your agent's hooks. No model runs at check time.
